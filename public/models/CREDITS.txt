skater.glb - Downhill Rush rider
================================

Built by `npm run build:skater` (tools/skater/build-skater.mjs) from:

* Universal Base Characters (Standard) by Quaternius - https://quaternius.com
  Superhero male body, eyes, eyebrows, skeleton, "Buzzed" hairstyle, skin/eye/hair textures.
  License: CC0 1.0 Universal (public domain dedication).

* Universal Animation Library (Standard) by Quaternius - https://quaternius.com
  "Death01" clip, retargeted onto the base character skeleton (used for wipeouts).
  License: CC0 1.0 Universal (public domain dedication).

The hoodie, trousers and sneakers are generated by tools/skater/garments.mjs from the
body surface and inherit its skin weights. The skating clips (ride, lean, crouch, ollie,
air, slide, kickflip, 360) are authored in code at load time (src/scene/character/skatePoses.ts).
